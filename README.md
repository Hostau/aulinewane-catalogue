# Catalogue AULINEWANE

Catalogue de sagas publié par AULINEWANE Saga Studio et lu par l'application Android TV.

- Point d'entrée : `catalog/manifest.json`
- Adresse publique : https://hostau.github.io/aulinewane-catalogue/catalog/manifest.json
- `BASE` à configurer dans l'application : `https://hostau.github.io/aulinewane-catalogue`

Ne modifiez pas ces fichiers à la main : chaque mise à jour vient d'un nouvel export « Dossier de publication » du Studio (numéro de version supérieur).
